#+TITLE: Entrusted document sanitizer tool

This application is being rewritten (usability, coding practices, maintainability).
  - The current code in this branch is a partial rewrite (still with Rust). Early versions of the app were written while learning Rust during the pandemic.
  - The upcoming version, likely in early/mid 2027 will be rewritten in C (local POC in progress while learning "just enough C").

* Changes
- General
  - The next version will be written mostly in C instead of Rust
- UI
  - There will only be a Web UI accessible via the Live CD (new theme and logo)
  - There will be support for encrypting sanitized PDF files
  - The Live CD itself will be smaller (hopefully around 300 MB or less) and faster to boot
- Processing
  - The docker/podman sandboxing approach has been removed in favor of a more direct/lower-level solution
  - The sanitization process is improving in term of logic, speed and memory efficiency
  - The optional OCR step will use modern approaches instead of Tesseract (older, slower, huge installation size and memory usage)

* Problems to solve

- Learn/understand enough C, to write code almost as quickly than in Java or Rust!
- Test additional security and sandboxing rules in the Live CD with other Linux distributions than Debian (current Live CD distro)
